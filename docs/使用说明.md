# 学生证工作室使用说明

## 第一次使用

解压对应系统发行包后启动。先载入演示资料，选择一个虚构学生查看预览，再执行生成。演示照片是绘制的人像，可能不能被人脸模型识别；此时会使用回退定位并将结果标为需要复核，这是预期行为。

程序不包含原 Notebook 引用的学校素材。实际制作需要准备以下文件：

| 材料 | 说明 |
|---|---|
| Excel 学生名单 | `.xlsx`，默认列为 `學號`、`Name`、`姓名`；可在界面映射为自己的列名 |
| 学生照片 | 文件夹或 ZIP；照片主文件名与学号一致，例如 `001234.jpg`；支持子目录 |
| 正面底图 | PNG/JPEG 等图片，使用与排版参数匹配的版本 |
| 照片遮罩 | 与底图等尺寸；白色部分显示照片，黑色部分保留底图 |
| 统一背面 | 生成 PDF 时使用 |
| 英文、中文、学号字体 | 可使用本机自动发现的字体，或手动选择 `.ttf/.ttc/.otf` |
| 输出目录 | 可写目录；每次任务在其下建立新子目录 |

学号最好在 Excel 中保存为文本。对于带纯零数字格式的数字单元格，程序会尝试按显示宽度补齐前导零；已经丢失且未设数字格式的零无法凭空恢复。公式学号应先在 Excel 中计算并保存，或转为文本。中文姓名为空或 `/`、`／` 时按没有中文姓名处理。

## 制作学生证

1. 选择名单、照片、底图、遮罩和输出目录；需要同时生成 PDF 时选择背面图片。
2. 执行输入检查。处理缺照片、同学号多张照片和重复学号等问题；有问题的记录会标记并跳过，其他有效记录继续处理，避免结果相互覆盖。底图、遮罩或必要模型等整体输入错误会阻止任务开始。
3. 选择一个学生预览。检查照片、中文字体、长英文名、条码与学号是否完整。
4. 按实际底图调整照片位置、亮度、脸部占比、姓名坐标和字号。默认坐标来自 Notebook；参考画布默认 648×1050 是桌面版的初始参考，不是对原底图尺寸的确认。换模板时必须重新确认预览。
5. 开始批量生成。界面保持响应，可查看进度及取消任务。
6. 打开新输出目录，查看 PNG、PDF、处理明细和任务清单。生成成功但人脸定位异常的照片仍需人工复核。

照片未识别到人脸时，程序使用中心回退位置；多人照片选择主要人脸并提示复核。模型不会替代最终证件照片的人工检查。

## 生成双面 PDF

可在学生证任务中一并生成，也可选择已有正面 PNG 的文件夹和统一背面独立生成。合并顺序为学生 A 正面、学生 A 背面、学生 B 正面、学生 B 背面，以此类推。

实际尺寸默认 54×85.6 毫米，可根据学校打印规格修改。打印时选“实际大小/100%”，避免打印软件再次缩放；先打印一张检查正反面对齐再批量打印。该尺寸是可调整的初始值，实际以学校要求为准。

## eClass 裁剪

选择照片文件夹或 ZIP 与输出目录即可。程序以人脸作为锚点，在原图范围内尽量保留最大面积，裁成宽高比 10:13；不改变原始照片。任务明细会记录不能读取或需要复核的照片。

## 结果与任务记录

每次运行会建立独立目录，避免覆盖旧任务。CSV 使用带 BOM 的 UTF-8，便于 Excel 打开中文；JSON 清单记录任务配置与结果。ZIP 汇集本次产物。取消操作会保留已经完成的结果并记录取消状态，不会把未完成任务当作全部成功。

处理真实数据后，输出目录与明细也包含学生信息，应按学校已有方式保存与共享。程序不会主动上传这些文件；GitHub 云端构建只需要程序源码和虚构演示资料。

## 常见情况

- 中文显示方框：手动选择本机可显示所需中文字符的字体，并再次预览。
- 照片未匹配：检查照片文件名是否等于 Excel 学号，尤其注意前导零和空格。
- 条码太宽或姓名超出：调整条码区域或姓名字号；预览后再生成。
- 无法写文件：选择当前用户可写的输出目录，并关闭正在占用结果文件的查看器。
- Mac 提示开发者无法验证：见 [Mac 云端打包](Mac云端打包.md) 中的签名和公证说明；机构管理的电脑可能由管理员控制能否运行。
