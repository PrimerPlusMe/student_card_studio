# 學生證工作室使用說明

## 製作學生證

1. 準備 `.xlsx` 名冊、按學號命名的 JPG/PNG 相片、原版 **649×1033 正面模板**、同尺寸 `psd_mask.png` 及輸出目錄。
2. 名冊第一個工作表首列須包含 `StudentID`／`學號`／`ID` 和 `Name`／`姓名`。班別及班號可省略；完整別名見 README。
3. 學號建議以文字儲存。文字 `00001` 及數字搭配 `00000` 格式皆保留前導零；已丟失的零無法猜測。公式欄位請先複製並貼上為值。
4. 相片放在資料夾第一層，主檔名須等於學號；副檔名不分大小寫。不支援 ZIP、子目錄、舊式 `.xls`。
5. 選擇照片遮罩及字體；留空時自動尋找模板同目錄的 `psd_mask.png`、`ARLRDBD.TTF`、`BiauKai.ttf`、`Arial.ttf`。遮罩不可缺少，找不到字體則使用系統字體；若要與 Colab 字形一致，應使用原字體。
6. 相片亮度預設 **1.2**，與原 Notebook 一致；若原照片已調亮，可改為 1.0。選擇是否綠幕退底及 **3×4 檢閱 PDF**，按「開始製作學生證」。一般白底照片不要勾選退底。
   若要正背面 PDF，填入統一背面（例如 `back2026.png`），勾選「同時生成每人正背面 PDF 及全班總 PDF」。留空時會找模板同目錄的 `back2026.png`。預設每面 54×85.6 mm，可按實際規格修改。
7. 在完成視窗查看實際輸出路徑、成功／失敗及錯誤。先以少量學生核對模板、人像和文字，再批次處理。

重複學號、同學號多張相片、缺圖、壞圖和缺少姓名會使該筆失敗，其餘資料繼續處理。必要欄位、名冊、模板或模型等整體錯誤會中止任務，介面會恢復可操作狀態。

使用原 Colab 的固定座標，不再採左側矩形照片與右側文字的通用版型：

- 鼻尖錨定照片、臉寬佔直徑 0.32、裁為 340×340，貼於 `(155,347)`，再以原廠遮罩合成。
- 有中文姓名：英文中心 `(324,742)`、46px；中文中心 `(324,812)`、65px。
- 無中文姓名：英文中心 `(324,768)`。不顯示「Name／Student ID／Class」標籤及班別文字。
- Code128 位於 `(149,863)`、350×90；學號頂部中心 `(324,960)`、42px。長條碼採整數模組避免失真；超出固定區可讀容量時會明確報錯。
- 姓名過長時才自動縮小，短姓名維持原字級及中心。單張輸出 PNG。

模型仍使用內附 YuNet，不是 Colab MTCNN；臉框／鼻尖可能不同，不能宣稱人像像素級一致。遮罩外的校徽及底圖不被矩形照片覆蓋。

## 檢閱 PDF

只保留單面 A4、3 欄 4 列、每頁最多 12 張的檢閱檔 `student_cards_review_3x4.pdf`。卡片維持原比例並依名冊順序排放；不足 12 張的格子留白。

這是檢閱用縮放排版，不代表卡片實體尺寸。**移除的是 A4 多張雙面列印排版**；下述每人兩頁正背面 PDF 是獨立功能。

## 每人正背面 PDF 與全班總 PDF

- 製卡時勾選後，輸出 `individual_pdfs/`：每位學生各一個 PDF，第 1 頁為正面、第 2 頁為統一背面。
- `All_Students_Combined.pdf` 合併所有成功個別 PDF，依正面檔名排序，頁序為「學生1正面、學生1背面、學生2正面、學生2背面……」。21 位應為 42 頁。
- 圖片無損嵌入，透明區補白，等比例置中；不拉伸、不翻轉、不做 A4 拼版。預設每頁 54×85.6 mm，可修改。實體印製請自行確認尺寸並以 100% 縮放列印。
- PDF 失敗數與製卡失敗數分開顯示；生成或合併失敗會警告，已完成 PNG／個別 PDF 保留。總檔僅包含成功生成的個別 PDF。

### 不重做學生證，僅產生 PDF

第三分頁「僅生成正背面 PDF」：
1. 正面圖片目錄選取之前製卡結果的 `single_cards/`（不要選原始學生照片目錄）。
2. 選擇統一背面圖片，指定輸出目錄和每頁尺寸。
3. 按「生成個別 PDF 及合併總 PDF」。不需要名冊、模板、字體或人臉模型。
4. 新的 `pdf_…/` 下會有 `individual_pdfs/` 和 `All_Students_Combined.pdf`。

只掃描目錄第一層 JPG/PNG，不掃描 PDF。不相關圖片不要放進正面目錄；相同主檔名的兩個圖片會報錯，避免靜默覆寫。

## 保留上次操作

三個分頁的所有路徑、製卡選項、亮度、PDF 尺寸、介面語言與目前分頁會自動保存，正常關閉再開啟仍還原。開始工作及關閉時也立即保存。記錄不因外接磁碟暫時離線而刪除，但執行時必須掛載磁碟。

本機 macOS 設定檔預設為 `~/.config/StudentCardStudio/StudentCardStudio.ini`。程式不將設定上傳或打包，測試／演示也不覆寫實際設定；請注意路徑本身可能含個人資訊。

## eClass 相片

第二分頁可獨立批次裁剪，無需名冊或模板。恢復原 Colab **10:13 最大面積保留**：寬圖保留高度、以臉水平置中；長圖保留寬度、臉中心偏上約 35%。為精確整數比例，最多多裁去 12px，不放大成近臉特寫。

偵測到多人時採最大人臉；無人臉時使用水平中央、垂直 40% 錨點。模型不等同人工審核，請檢查頭部、肩膀與邊緣。圖片讀取會依 EXIF 方向旋轉，不保留原相片的 EXIF 資訊。

## 輸出與執行保護

- 每次在所選目錄下建立新的任務子目錄，不覆寫先前成果。
- 製卡產生 `single_cards/`、`cropped_photos/`；有勾選且成功時另產生檢閱 PDF、個別 PDF 及總 PDF。
- `single_cards/` 為 PNG；`cropped_photos/` 是未調亮、未去背的 10:13 裁剪照片；亮度與白底處理只套用於卡片。
- 輸出不可選在來源相片目錄或其下，避免混入後續輸入。
- 執行中停用三個工作分頁，不能同時開始另一任務；關閉視窗會被攔截，請等候任務完成。目前不提供取消功能。
- PDF 生成失敗會保留已完成卡片、顯示警告，且不列出不存在的 PDF。
- 程式不會主動上傳資料；輸出檔名仍含學生資訊，請以校方規範保存。

目前不提供預覽編輯器、CSV/JSON 明細或結果 ZIP。Mac 發行說明見 `Mac云端打包.md`。
